# 妙妙二玩箱品牌资源

英文工程名继续使用 ErYouToolbox。ICO 与 PNG 均为用户提供的品牌图标；用户于本轮明确确认拥有或获得公开源码与 Windows 包分发权限。未生成替代素材。

- ICO：Windows EXE、窗口、任务栏及 Alt+Tab 图标。
- PNG：React 首页品牌标记。
- windows_version.txt：Windows 中文产品名称和文件描述；内部名称保持 ErYouToolbox。

资源以只读文件随包分发，不放入 userdata，不影响现有个人状态。Windows 快捷方式由用户自行创建，默认继承 EXE 图标；更新后 Explorer 若仍显示旧图标，请先从新解压路径检查，勿删除用户数据或浏览器缓存。
