# OB5-C UI收敛验收

本轮只修改前端六个文件：App.tsx、SyncCheck.tsx、AutoSyncSettings.tsx、Authors.tsx、RelatedMods.tsx、styles.css；扩展tests/ui_navigation_smoke.cjs用于隔离截图和交互验证。保留OB5-A/OB5-B既有未提交成果，没有修改后端、数据库、任务、作者轮转或图片回填。

## 可见变化

- 同步控制默认收起为74px条带，显示保存的自动模式、间隔、运行/待确认/失败、最近结果及立即检查。完整操作仍在展开区，包括原模式保存、任务状态、页数、各游戏统计、预览确认/放弃及错误信息。
- 控件使用hidden隐藏而非条件卸载，AutoSyncSettings保持挂载和原有轮询。展开不会重启任务、重新读取设置或丢弃候选；立即检查仍调用原手动检查接口，不会自动确认入库。
- 我的关注使用响应式卡片，宽桌面4列、较窄桌面3列，更窄继续减少。关注管理放入二级details，保留搜索和分页。
- 关联作品改成小封面+标题的四条列表，身份、链接、图片开关和评级过滤保持；不再渲染完整MOD卡片。
- 内容分级默认折叠并显示选择数，原checkbox和筛选状态保留，全选默认不变。主列表额外技术说明收进原位details，没有删除。

## 本机验收与限制

使用原启动器重启前端，验证真实数据和实际缩放比例。先查看折叠条的待确认/失败提示，再展开确认旧操作齐全；不要为了视觉验收点击真实确认入库或随意取消真实关注。

没有新增前端依赖、没有下载真实图片、没有调用真实GameBanana或执行Git推送。未实测生产数据的全部长标题/错误组合、非100%浏览器缩放和所有小屏尺寸；异常文字可能让条带换行，高度目标针对正常桌面状态。展开偏好不持久化，刷新默认收起，原同步设置不变。
