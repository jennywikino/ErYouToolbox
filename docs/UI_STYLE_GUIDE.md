# ErYouToolbox UI Style Guide

当前界面采用深色游戏工具风格。新增页面和组件应优先沿用 Streamlit 原生控件与这些基础规则。

## 色彩

- 页面背景：`#101820`
- 卡片：`#202B36`
- 侧边栏与次级表面：`#18212C`
- 主强调色：`#55CABB`
- 图片选中边框：`#55CABB`
- 主文字：`#E6EDF3`
- 次级文字：`#B9C5D0`

## 层级

- 页面标题最突出；卡片标题次之，最多两行。
- 作者、游戏、日期等元数据使用较小但清晰可读的文字。
- 操作入口使用简短动词，详情与原帖入口保持区分。
- 未评级作品保持 UNKNOWN 语义，是否展示预览由会话开关控制。

## 间距与形状

- 卡片列间使用 Streamlit `small` 间距；卡片之间约 `0.75rem`。
- 卡片内边距约 `0.8rem`。
- 按钮圆角约 `8px`，图片与占位区域约 `6px`。
- 图片保持原始宽高比；无图占位区域比常规预览更矮。

## 页面布局

- 桌面宽屏首页使用四个独立纵向列，当前分页排序结果按 round-robin 分配，每列内部从上到下排列。
- 该原生布局避免重复创建行列，属于轻量瀑布流近似；不会根据实际渲染高度动态重排，不能保证最短列优先填充。
- 详情弹窗继续使用约 `3:2` 的图片与信息分栏。
- 侧边栏建议宽度约 `280–320px`，内容区使用剩余宽度；避免让筛选控件挤压主内容。

紫色可作为少量辅助色的后续候选，但不要引入未授权的品牌素材或复制其他产品的内部设计资产。
