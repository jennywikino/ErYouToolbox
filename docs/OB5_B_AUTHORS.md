# OB5-B 我的关注与本地作者作品

## 页面与查询

订阅顶部“我的关注（N）”折叠面板读取SQLite真实关注数量。支持名称搜索、每页20位作者、来源和作者ID联合身份、取消关注及作者作品入口。以最近本地作品的有效发布时间排序，无有效日期时按来源和作者ID稳定排序。

作者作品页沿用现有列表卡片、游戏/搜索/排序/已阅/图片/评级筛选及SQL LIMIT/OFFSET分页。作者信息旁显示的是本地收录数量，不是来源全部作品。头像/作者名称可进入站内作者页，另保留原站主页链接。

详情右侧增加最多4条该作者其他本地作品，按最近发布排序，SQL排除当前MOD。使用已有小图字段、评级过滤、图片开关和占位处理，不额外取高清元数据。点击继续复用原详情与已阅行为；只浏览作者列表和查询不会修改已阅状态。

作者source+author_id存入原浏览快照，详情返回、后退前进可恢复。作者页hash支持刷新直接打开。没有新路由框架，也没有改动作者自动检查器、同步或表结构。缺少发布时间时显示未知，不从首次发现时间推断新作。

## Member头像验证与缓存

真实只读验证2次：作者2201879、2737800，Core/Item/Data itemtype=Member、return_keys=1，字段name、Url().sAvatarUrl()、Url().sHdAvatarUrl()、Url().sProfileUrl()。两次均HTTP200、返回按字段名组成的JSON对象，主页URL分别精确匹配所请求作者ID。两位均有普通头像URL，一位高清头像为空。

头像仅接受HTTPS images.gamebanana.com/img/av/路径，拒绝外部域名、认证信息、异常端口、fragment/query和路径穿越。以返回的GameBanana成员主页URL校验身份。没有抓HTML，也没有下载头像本体或MOD文件。

已验证的两条URL元数据缓存于logs/author_profiles，成功有效期7天；普通失败负缓存1小时，403/429保守缓存至少7天且尊重更长Retry-After。关注面板只读缓存、不为每个作者或MOD卡片发起来源请求；只有进入具体本地作者作品页时才可能查询一次过期资料。API进程内串行缓存读取/更新，重复访问复用缓存。失效图片、缺失头像或请求失败显示首字母占位。URL元数据及运行日志被Git忽略，不含图片文件。

真实验证证明来源提供合法头像URL，未在真实浏览器下载/渲染该图片，不能声称头像加载已实测成功。

## API

- GET /api/authors：关注作者分页、搜索及统计，只读。
- GET /api/author?source=...&author_id=...：仅查询本地已存在作者，附带受限头像缓存。
- 既有GET /api/mods增加author_source、author_id、exclude_id过滤；仍参数化、过滤后分页。
- 关注修改继续调用现有受限本地写入接口，本轮没有对真实关注关系执行修改。
