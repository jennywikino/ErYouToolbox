# OB2-A 浏览状态恢复

只调整浏览状态与验收测试，不修改采集、数据库、已阅行为、分级、画廊或热门算法。

## 审计与修复

现有路由是hash + History API，无第三方路由库；列表通过hidden保留DOM。已有顶层筛选快照和两秒锚点校正，但热门参数在PopularPanel内部，刷新详情后丢失；原恢复逻辑也没有等待热门分组异步请求。

本轮将热门sort/scope/days/maxPages、每游戏分组loaded/page纳入App浏览快照。保存分区、游戏、已提交与草稿搜索、排序、分级、已阅、图片筛选、页码、原滚动像素、source/item_type/item_id锚点和锚点视口偏移；额外保留游戏身份以等待正确分组。

使用现有history.state，不引入路由框架；旧快照缺热门字段时兼容默认值，损坏或缺失快照忽略。刷新详情保持安全，直接链接没有快照时返回默认作品库。

返回等待实际列表查询key一致，或对应热门分组data-ranking-ready。MutationObserver/ResizeObserver结合动画帧处理异步渲染；先锚点后像素降级，用户滚动/点击/按键立即终止校正。已阅筛选使原作品移出结果时用像素备用位置。分区/游戏主动切换继续回顶部并清除旧锚点。

热门详情隐藏时暂停尚未必要的列表请求，普通返回保留同条件数据；刷新详情后返回仅重新读取必要页。没有更改缓存或热门排序算法。

## 实际浏览器证据

真实隔离Chrome + 临时Vite端口；72条合成作品，18条本地分页，20条热门分页；所有API与图片请求拦截为临时数据，模拟图片延迟、热门响应600ms。没有生产数据库写入或真实图片下载。

- 最新MOD第三页中部：返回锚点误差0px，页索引2保留。
- 订阅动态：分区保留，锚点误差0px。
- 已阅筛选：保留read状态，锚点误差0px。
- 热门：recent/7天/views/第二页保留，普通返回误差0px且额外榜单请求0次。
- 刷新热门详情后返回：同一参数与第二页保留，误差0px，必要榜单请求1次。
- 内部返回、浏览器后退/前进通过；游戏切换scrollY=0；搜索、游戏、排序及第二页检查通过；浏览器异常0。

最终证据保存在忽略的logs/ui_smoke/ob2a_verified_1793339277430/report.json；额外确认图片筛选true、分级[UNKNOWN]恢复。最终代码含历史快照输入校验，10项前端单元测试及构建通过。

这些是实际浏览器操作，但数据是模拟数据，不等同于生产内容人工验收。前端状态只用浏览器URL/history，不含E/F盘路径；本轮未实际切换F盘。

## 本机验收

在frontend目录执行pnpm.cmd test、pnpm.cmd build；从项目根运行node tests/ui_navigation_smoke.cjs ob2a_verify可重做隔离浏览器操作（需已有Chrome，不安装新依赖）。

重启现有工具盒后，分别在最新第三页、订阅、热门带时间窗口和排序的第二页中部打开本地详情，点击返回并测试后退/前进；再刷新详情后返回，核对原参数。检查已阅/分级/图片筛选保留，主动切换游戏回顶部。生产内容有增删时允许降级到原像素位置，不保证已移出的作品仍可作为锚点。
