# MAINT-1：角色名称库维护

2026-11-04。实现完成、关联测试及构建通过；真实桌面面板操作待人工验收。本轮不打包、不提交、不发布，不扩充内置269个中文检索键。

## 使用

最新 MOD → 更多设置 → 角色名称库。选择六游戏之一，按中文、英文或别名查询；每页20个名称。点击名称填入编辑区。保持名称不变可替换其别名；改变名称会添加新检索键，旧键需要单独删除。

新增、修改、删除、本地导入、GitHub更新、恢复和重置均先预览，再点击“确认保存名称库”。预览10分钟有效；其间名称库发生改变需重新预览。关闭或放弃不会保存。个人修正高于导入，高于内置；删除使用个人层屏蔽标记，不修改内置文件。重置清除导入及个人层，保留原始内置索引及受保护的官方名称。导入采用同游戏、同名称覆盖式合并，其他名称保留；个人修正始终优先。预览同时显示导入层、个人层变更数，以及有效搜索名称的前后差异。

保存后下一次提交搜索立即读取新名称库，不必重启或重新打包。不会主动重发当前列表查询。现有 `search_info.alias_known` 区分词库命中和本地无作品；任何词库操作都不会创建虚构 MOD。适用于经过本地 API 的本地作品搜索；不增加远程热门榜翻译或自动网络检索。

## 统一交换格式

```json
{
  "format": 1,
  "games": {
    "20357": {
      "锁暝": ["Suoming", "鎖暝", "Suo Ming"]
    }
  }
}
```

游戏 ID：8552、18366、19567、20357、21842、23012。仅支持此版本格式；可选 sources 仅作说明，不执行、不作为可信证据。上限512 KiB、3000个名称、每名称1–16个别名、每名称/别名80字符；拒绝空项、控制字符、HTML尖括号、异常游戏及格式。完整状态也有512 KiB限制。浏览器本地文件先检查大小，服务端再次校验内容。

GitHub仅接受 `https://raw.githubusercontent.com/owner/repo/ref/path.json`；拒绝其他主机、凭据、端口、查询参数、片段、父目录路径及重定向，不解析仓库/ZIP/脚本。一次点击一次串行HTTP获取，不重试、不定时；单次网络读超时15秒，持续读取超过30秒退出。403/404/429/超时等作为错误显示，不修改已保存词库、不自动重试。远程服务不保证可访问，HTTP处理已离线模拟验证，未实际下载第三方维护库。

## 持久化、备份与恢复

- 桌面版：EXE旁 `userdata/data/character_library/library.json`。
- 开发版：运行根目录下 `data/character_library/library.json`。
- 同目录 `backup-<随机ID>.json`：每次实际变更前保存旧导入层/个人层并flush/fsync。备份失败不替换正式文件；临时文件写完fsync后原子替换；保存失败保留旧库。
- 界面可选择最近50个备份文件之一预览恢复；不自动删除任何旧备份（选择列表按文件名排列，不表示生成时间）。导出有效词库得到统一交换JSON，包含内置、导入及个人修正的当前有效结果；**不等同于完整层级备份**，完整层级由自动备份保存。
- 内置库不变；库损坏会明确报错，不静默覆写为空。恢复入口依赖主状态能读取，严重损坏时需关闭客户端，从同目录有效备份手动恢复 `library.json`，保留损坏副本。
- 整个userdata一起搬移到E/F盘后相对路径不变。无新增SQLite字段，无SQL写入，不触碰已阅、关注、同步检查点或MOD数据。
- 备份仅保护词库，不代替独立灾难恢复备份；复制便携userdata时应连同该目录保存。本轮未扩展既有项目整包备份清单。
- API沿用Host/Origin、`X-ErYouToolbox: 1`、JSON限制；名称库接口单独放宽请求体至600 KiB，其他接口仍2048字节。预览基线校验阻止已知的并发旧预览提交，进程内串行；不支持多个独立API进程同时维护同一目录。
