## 本机验收

1. 使用现有关闭/启动入口重启工具盒，进入最新MOD。
2. 点击检查当前游戏验证旧流程，再点击检查全部游戏，确认游戏串行推进、请求数和各游戏结果。
3. 查看结果后由用户点击确认导入；核对列表自动刷新、原有已阅/图片/分级和订阅保留。
4. 再次检查确认应不重复插入作品或事件。部分失败时只能确认成功游戏候选；限流后的游戏应显示未执行。
