# ErYouToolbox V0.1

## Completed

- Bounded GameBanana `apiv11/Mod/Index` collection, normalization, deduplication, and dry-run/apply sync.
- SQLite schema, safe sample import, metadata/source event detection, backup support, and read-only backup/restore verification.
- Per-game bounded history backfill with separate creation/update windows and conservative coverage reporting.
- PowerShell bootstrap and probe entry points; no UI or scheduled/cloud sync.

## Verified games

Genshin Impact (8552), Honkai: Star Rail (18366), Zenless Zone Zero (19567), Wuthering Waves (20357), Arknights: Endfield (21842), Neverness to Everness (23012).

## Verification

- Six-game public API collection and pagination were exercised in bounded samples.
- Per-page size 50 was verified against Genshin Impact; 50 records returned with `_aMetadata._nPerpage=50` and game ID 8552.
- SQLite backup/restore drill passed: integrity check `ok`, no foreign-key violations, and matching table counts/version.
- Latest local regression run: 100 unittest cases passed.

## Known limits

- Bounded pages and observed timestamp boundaries do not prove complete historical coverage or absence of pagination drift.
- Content rating remains `UNKNOWN` unless reliable source evidence is available.
- No UI, scheduler, cloud sync, bulk historical backfill, or automatic file/image downloads.

## V0.2 follow-up

- Design resumable, drift-aware backfill checkpoints and reconciliation for missed pages.
- Add a review workflow for coverage and source metadata quality before expanding automation.
- Consider a local UI only after the data and recovery workflows are stable.
